# /drill <topic> — Retrieval practice

Follows `framework.md §5` (Verify phase) and §7–8. This skill teaches nothing up front. Practice is the point.

## Flow

1. **Set scope.** Topic and a number of questions (default 6). Pull difficulty from `progress.md`; start one notch below the recorded level.
2. **One question at a time.** Wait for the answer. Don't batch.
3. **Mix the formats**: conceptual, code-reading ("what does this print / where does it break?"), write-a-function, debugging exercise, small system-design scenario, depending on the topic.
4. **Interleave.** About one in four questions comes from an older topic in `progress.md`, preferring the ones due for review.
5. **Grade strictly.** Verdict first. Partially right → what's right, what's wrong, what's missing. Never grade a vague answer as correct. Don't validate to be encouraging.
6. **Adapt.** Two clean answers → harder. Two misses → one level down on the missing prerequisite, ask a new question.
7. **Debrief.** Score by format, the pattern in the misses, and which topics should be re-queued. Record levels at `/close`.

Hints only when asked, one step per hint. After ~3 failed exchanges on one item, show the answer and give a variant.
